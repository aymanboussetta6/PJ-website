# Photos du site

Déposez ici les photos (JPG, PNG ou WebP, idéalement ≥ 1600 px de large, format paysage).
Elles sont optimisées automatiquement au build (WebP, tailles adaptées au mobile).
Tant qu'une photo manque, un fond dégradé bleu s'affiche à sa place.

| Nom de fichier        | Emplacement                                   |
| --------------------- | --------------------------------------------- |
| `hero.jpg`            | Grande image d'accueil (pylône, antennes…)    |
| `studies.jpg`         | Bureau d'études                               |
| `infra.jpg`           | Déploiement infrastructure télécom            |
| `radio.jpg`           | Déploiement radio                             |
| `maintenance.jpg`     | Maintenance curative et préventive            |
| `fiber.jpg`           | Fibre optique                                 |
| `civil.jpg`           | Génie civil                                   |
| `energy.jpg`          | Électricité et énergie                        |
| `microwave.jpg`       | Faisceaux hertziens                           |
| `commissioning.jpg`   | Commissioning et mise en service              |
| `careers.jpg`         | Section « Rejoignez nos équipes »             |
| `founder.jpg`         | Portrait du fondateur (page Fondateur, format portrait 4:5) |

Utilisez de préférence vos propres photos de chantier (avec l'accord des personnes visibles),
ou des photos sous licence libre d'usage commercial.
